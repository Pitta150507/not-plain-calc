# Final Product-Recognition Icon Pass

Goal: find the production icon for Not Plain Calc by using the Macintosh Refined interface itself as the source of recognition.

The final icon direction is not an abstract symbol, a mini calculator, or a generic utility mark. It is a distilled fragment of the shipped product: inset display well, keypad plate structure, physical key geometry, cream/platinum material language, and a coral equals key.

## Candidate Ranking

1. **Candidate E - Disciplined Product Crop**
   - File: `candidate-e-disciplined-product-crop.png`
   - Winner. Best balance of product recognition, 60px readability, and App Store polish.
   - Shows display well, keypad plate, one blank physical key, and coral equals key without random symbols.

2. **Candidate B - Tight Product Crop**
   - File: `candidate-b-tight-product-crop.png`
   - Strong and product-specific, but more crop-heavy and slightly less balanced than E.

3. **Candidate A - Keypad Plate Crop**
   - File: `candidate-a-keypad-plate-crop.png`
   - Clear product structure, but the left-side cropped key makes the composition feel less resolved.

4. **Candidate C - Neutral Structure**
   - File: `candidate-c-neutral-structure.png`
   - Useful neutral validation, but too anonymous without the final-action color cue.

5. **Candidate D - Bottom-Right Fragment**
   - File: `candidate-d-bottom-right-fragment.png`
   - Rejected because the adjacent dot reads as a random symbol.

## Final Decision

Candidate E replaced `assets/icon.png`.

The previous production icon was archived as `assets/icon-rejected-random-keypad.png` because it included random numbers, duplicate symbols, and a confusing keypad layout.

## App Store Suitability

- Recognizable at 60x60.
- Directly connected to the current Macintosh Refined UI.
- Avoids Apple logos, Macintosh hardware, old system windows, random keys, fake screenshots, and generic abstract icon trends.
- Low practical IP risk because it derives from original Not Plain Calc UI elements.

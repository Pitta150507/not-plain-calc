# GitHub Pages Setup

The public pages for Not Plain Calc live in this `docs/` folder and are ready for GitHub Pages.

Expected public URLs after setup:

- Marketing page: `https://pitta150507.github.io/not-plain-calc/`
- Privacy Policy: `https://pitta150507.github.io/not-plain-calc/privacy.html`
- Support: `https://pitta150507.github.io/not-plain-calc/support.html`

## GitHub Setup

1. Open the repository on GitHub: `https://github.com/Pitta150507/not-plain-calc`.
2. Click **Settings**.
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
5. Set **Branch** to `main`.
6. Set the folder dropdown to `/docs`.
7. Click **Save**.
8. Wait for GitHub Pages to finish publishing. GitHub usually shows the published URL at the top of the Pages settings screen.

Do this before submitting Public TestFlight metadata so the support and privacy URLs are live.
